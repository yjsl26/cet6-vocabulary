# 每日六级单词卡

手机优先的纯静态页面，无需安装依赖或构建。入口是根目录 `index.html`。

## 运行

- 电脑：下载仓库后直接打开 `index.html`。脚本采用普通相对路径，支持本地打开；本地文件页面的浏览器存储支持因浏览器而异。
- 推荐预览：在仓库目录运行 `python -m http.server 8000`，打开 `http://localhost:8000`。手机与电脑处于同一 Wi-Fi 时，访问 `http://电脑的局域网IP:8000`（需允许本地网络访问）。
- 手机长期使用：在 GitHub 仓库 Settings → Pages，选择 Deploy from a branch，选择 `main` 和 `/ (root)`，保存。部署成功后打开 `https://yjsl26.github.io/cet6-vocabulary/`。本提交没有自动启用 Pages，也不保证该地址已经上线。

## 功能

点击单词显示中文，停留 2 秒自动进入下一词；可手动跳过，或暂停自动切换。最后一词后显示完成，可重新学习。切换学习范围会取消旧倒计时。离开页面暂停倒计时，返回后重新计时。

今日新增与历史词库分别保存学习位置。日期以设备本地日期为准。当天没有新批次时明确显示“今日暂无新增”，仍可复习历史。跨天自动刷新学习范围。

全部已到日期的批次都会加载，不要求用户每天访问。相同单词按忽略大小写去重，保留已存在的释义与首次收录日期。历史和进度保存在当前浏览器的 localStorage；不会跨设备同步，清理浏览器数据会清除进度，但仓库中保留的词库会重新载入。

## 每日追加：保留所有旧批次

编辑 `data/words.js`，只在 `WORD_BATCHES` 数组末尾追加对象，日期用 `YYYY-MM-DD`：

```js
{date:'2026-10-21',words:[
  {word:'例词的英文',meaning:'词性与中文释义'}
]}
```

请替换示例内容，不要把它作为正式词条提交。未来日期批次到当天才出现；重复词不会算作新词。不要删除历史批次或覆盖旧文件中的词条，否则新设备无法取得完整历史。页面会自动按日期合并，但静态网页不会自行生成、抓取或提交新词：每天仍需维护者追加，或预先写入未来批次。已打开的页面要刷新才能取得新发布的数据。

## 当前缺少的词库数据

仅有 2026-10-19 的 3 词和 2026-10-20 的 5 词，共 **8 个演示词**，用于验证交互，不是完整六级词库，也不是已审核的考试大纲清单。

仍缺：合法来源且明确版本的完整六级词表、逐词核对的词性与中文释义、后续每日分组计划。音标、例句、发音音频尚未提供，页面当前也不依赖这些字段。

## 目录与验证

```
index.html           页面入口
assets/style.css     手机布局
assets/core.js       日期、追加合并和筛选
assets/app.js        单词交互与本地进度
data/words.js        按日期追加的词库
tests/core.test.cjs  历史保留、去重与日期验证
```

安装 Node.js 后运行 `node --test tests/*.test.cjs`。
